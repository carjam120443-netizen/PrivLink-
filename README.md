# PrivLink

Independent Android privileged-service manager prototype.

## v0.1.0
- Material 3 Compose UI
- Foreground service
- Start/stop controls
- Root and ADB launch modes planned

The current service is intentionally unprivileged. Root/ADB launchers and Binder/AIDL IPC are the next implementation stage.

Open the repository in Android Studio, sync Gradle, and build the app module.
